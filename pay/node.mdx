AiFinPay is payment infrastructure for AI agents. The Node SDK lets an agent hold its own non-custodial wallet, answer an HTTP **402** from an AiFinPay merchant with a payment, and get the paid response back in one call.

Agents pay in USDC or POL from their own wallet on Polygon. There is no AiFinPay token and no balance held by AiFinPay.

<CurrentVersions />

## Install

```bash
npm install @aifinpay/agent
# or: pnpm add @aifinpay/agent
# or: yarn add @aifinpay/agent
```

<Info>
The package ships as ESM (`"type": "module"`), so the top-level `await` used in the snippets below works directly in a `.mjs` / `.ts` module.
</Info>

## Load the wallet

Load the wallet you already configured before sharing a deposit address:

```ts
import { AiFinPayAgent } from "@aifinpay/agent";

const agent = await AiFinPayAgent.fromEnvironment();
console.log({ evm: agent.evmAddress, solana: agent.solanaAddress });
```

`fromEnvironment()` only loads; it never creates or overwrites a wallet, prints its keys, or calls the network. It selects one identity in this order, the same as the MCP server:

1. `SEED_HASH`: a 32-byte seed encoded as 64 hex characters, optionally `0x` prefixed.
2. `./aifinpay/agents.json` relative to the working directory (`AIFINPAY_AGENTS_FILE` for another path, `AIFINPAY_AGENT_ID` to pick one of several records).
3. `AIFINPAY_AGENT_SECRET`: an existing base58 Solana secret.
4. `~/.aifinpay/agent.json`, or `AIFINPAY_HOME/agent.json`: the MCP keystore. Encrypted keystores need `AIFINPAY_WALLET_PASSPHRASE`.

Missing configuration, an invalid seed or a decryption failure throws instead of selecting a new wallet. Load any `.env` through your runtime first; the SDK reads `process.env` only.

`AiFinPayAgent.new()` creates a fresh wallet each time and does not persist its keys. Use it only when you will store the recovery material privately before funding it, and never rerun it to recover a funded address. `AiFinPayAgent.fromSeed(seed, { derivationIndex })` selects a child wallet of the same seed.

## Fund the EVM address

Send POL, or USDC plus a little POL for gas, to `agent.evmAddress` on Polygon. The smallest payment is $0.02, and gas is paid separately from your wallet.

## Your first paid call

`fetchPaid(url, init, opts)` makes the request. On an AIFP-1 `402` it gets a signed quote, settles one batch from the agent's wallet, exchanges it for a receipt and retries; later requests the receipt covers cost no transaction.

```ts
import { AiFinPayAgent } from "@aifinpay/agent";

const agent = await AiFinPayAgent.fromEnvironment();
agent.setBudget({ daily_usd: 1.0, per_call_usd: 0.05 });

const url = "https://wp-demo.aifinpay.io/wp-json/aifinpay-demo/v1/market-snapshot";

const response = await agent.fetchPaid(
  url,
  {},
  {
    gatewayOrigins: ["https://wp-demo.aifinpay.io"],
    resourcePathMode: "direct",
    scope: "exact",
    maxAmountUsd: 0.05,
    nativeUsdPrice: readFreshIndependentPolPrice,
    v14: {
      maxGasWei: ownerGasLimitWei,
      onPrepared: persistPrivatePaymentJournal,
    },
  }
);

if (response) console.log(response.status, await response.json());
```

The demo route is priced at $0.0005 per request; the smallest payment, $0.02, buys a batch of requests.

You supply three things:

- `readFreshIndependentPolPrice` returns `{ usd, observedAtMs }` (sync or async) from a POL/USD source you trust. It is called only when buying, never when reusing a receipt.
- `ownerGasLimitWei` is your gas budget in wei for approval plus settlement. Gas is separate from the USD limits.
- `persistPrivatePaymentJournal` receives the quote, chain, transaction hash and signed transaction. It must persist and fsync them privately before it resolves; if it fails, nothing is broadcast. Never log the raw transaction or the receipt.

Nothing is signed unless the origin is in `gatewayOrigins`, the signed quote matches the challenge and the SDK's pinned deployment, and the batch fits your limits.

## Limits

- `setBudget({ daily_usd, per_call_usd })` caps spend over 24 hours and per call. `agent.getSpend24h()` reads the rolling total.
- `maxAmountUsd` caps one purchase.
- `v14.maxGasWei` caps gas.

Polygon is the default. To pay on another network the merchant accepts, set `v14.chain` yourself; a quote never chooses the chain for you.

## When a payment does not finish

- **Transport error after paying.** Call `agent.recoverPaidPayment(recovery)` with the recovery object your `onPrepared` saved. It retries receipt issuance only and never sends a second transaction.
- **`Aifp1ActiveReceiptError`** (`code: "AIFP1_ACTIVE_RECEIPT"`). Within a minute of a settled purchase, the same payer and resource get the existing receipt instead of a quote. Nothing was quoted or paid. Recover it from the recovery saved for `e.txRef`:

  ```ts
  import { Aifp1ActiveReceiptError } from "@aifinpay/agent";

  try {
    return await agent.fetchPaid(url, {}, opts);
  } catch (e) {
    if (!(e instanceof Aifp1ActiveReceiptError)) throw e;
    const paid = await agent.recoverPaidPayment(savedRecoveryFor(e.txRef));
    return fetch(url, { headers: { "AIFP-Receipt": paid.receipt } });
  }
  ```

  Do not retry `fetchPaid` to get past it: once the minute is over, a new quote is a new purchase.
- **`Aifp1MerchantChangedError`** (`code: "AIFP1_MERCHANT_CHANGED"`). A gateway site (`https://gateway.aifinpay.io/<slug>`) is pinned to the merchant it was first paid as. If the change is legitimate, say so for that call with `{ allowMerchantChange: true }`, or name the merchant you trust with `{ expectedMerchantId: "mrch_…" }`.
- **`Aifp1GatewayRetiredError`** (`code: "AIFP1_GATEWAY_RETIRED"`). The slug answers `410 gateway_retired`. Do not retry it.

## Link the agent to your dashboard

At [dash.aifinpay.io](https://dash.aifinpay.io) → **My Agents** → **Add agent by address** you get a challenge. Sign it and hand back the signature:

```ts
const signature = await agent.signDashboardClaim(challenge);
```

`signDashboardClaim` signs only `AiFinPay-claim:polygon:<this address>:<nonce>` and refuses any other text. You then see the agent's balance, payments and receipts.

## Name the AI client that pays

Set `framework` and every request of the payment flow carries `AIFP-Agent-Framework: <value>`, so the merchant dashboard shows which AI client paid:

```ts
const agent = await AiFinPayAgent.fromEnvironment({ framework: "claude" });
```

Accepted values: `chatgpt`, `claude`, `perplexity`, `gemini`, `cursor`, `openai-agents`, `windsurf`, `codex`, `custom`. Leave it unset and no header is sent.

The provider bridge (`agent.pay` to the AiFinPay bridge host, `call()`) was retired on 2026-10-12.
