`aifinpay-agent` is a non-custodial payment client for AI agents. The agent
holds its own wallet, answers an HTTP **402** from an AiFinPay merchant with a
payment, and gets the paid response back. The keypair is generated locally and
never leaves your process.

Agents pay in USDC or POL from their own wallet on Polygon. There is no
AiFinPay token and no balance held by AiFinPay.

<CurrentVersions />

## Install

```bash
pip install aifinpay-agent
```

The import package is `aifinpay`.

## Create the wallet

```python
from aifinpay.unified_agent import AiFinPayAgent

agent = AiFinPayAgent.from_seed(SEED_HEX)  # 32-byte seed you keep private
print("EVM address:", agent.evm_address)   # fund on Polygon: POL, or USDC + a little POL for gas
```

The same seed always gives the same addresses, in Python and in the Node SDK.

## Your first paid call

```python
r = agent.fetch_paid(
    "https://wp-demo.aifinpay.io/wp-json/aifinpay-demo/v1/market-snapshot",
    allowed_origins=["https://wp-demo.aifinpay.io"],  # the only origins it will pay
    max_amount_usd=0.20,                               # per batch
    daily_amount_usd=2.00,                             # rolling 24 h, persisted
    asset="USDC",                                      # or "POL" (default)
)
print(r.status_code, r.json())
```

The demo route is priced at $0.0005 per request. On an AIFP-1 `402`,
`fetch_paid` buys one batch (the minimum the 402 advertises, $0.02 by default),
settles it on Polygon, exchanges it for a receipt and retries. Later requests
the receipt covers cost no transaction.

Nothing is signed unless the origin is allowed, the signed quote matches the
challenge and the SDK's pinned deployment, and the batch fits both limits. POL
is priced against an independent POL/USD source, never the quote; USDC approves
exactly the batch.

## Limits

- `max_amount_usd` caps one batch; `daily_amount_usd` caps a rolling 24 hours.
  Processes that share one `journal_dir` share one budget.
- Gas is separate from the USD limits. On Polygon it has a default cap; every
  other network needs an explicit `max_gas_wei`.
- Polygon is the default. Omitting `chain` keeps Polygon even if a merchant
  advertises another network; to pay elsewhere, pass `chain` yourself.

## When a payment does not finish

Every settlement is journaled to `journal_dir` (default `~/.aifinpay/journal`)
before it is sent.

- **Unknown outcome.** `Aifp1PayError` carries `recovery["journal_path"]`; call
  `agent.recover_paid(path)`. Do not pay again.
- **`Aifp1ActiveReceiptError`** (`code = "AIFP1_ACTIVE_RECEIPT"`). Within a
  minute of a settled purchase, the same payer and resource get the existing
  receipt instead of a quote. Nothing was quoted or paid.

  ```python
  from aifinpay import Aifp1ActiveReceiptError

  try:
      r = agent.fetch_paid(url, ...)
  except Aifp1ActiveReceiptError as e:
      if not e.journal_path:
          raise  # no journal for e.tx_ref: buying again is a new payment, the owner's call
      agent.recover_paid(e.journal_path)
      r = agent.fetch_paid(url, ...)  # reuses the recovered receipt
  ```

  Do not retry `fetch_paid` to get past it: once the minute is over, a new
  quote is a new purchase.
- **`Aifp1MerchantChangedError`** (`code = "AIFP1_MERCHANT_CHANGED"`). A
  gateway site (`https://gateway.aifinpay.io/<slug>`) is pinned to the merchant
  it was first paid as. If the change is legitimate, pass
  `allow_merchant_change=True` for that call, or name the merchant you trust
  with `expected_merchant_id="mrch_..."`.
- **`Aifp1GatewayRetiredError`** (`code = "AIFP1_GATEWAY_RETIRED"`). The slug
  answers `410 gateway_retired`. Do not retry it.

## Link the agent to your dashboard

At [dash.aifinpay.io](https://dash.aifinpay.io) → **My Agents** → **Add agent
by address** you get a challenge. Sign it and hand back the signature:

```python
signature = agent.sign_dashboard_claim(challenge)
```

`sign_dashboard_claim` signs only `AiFinPay-claim:polygon:<this address>:<nonce>`
and refuses any other text. You then see the agent's balance, payments and
receipts.

## Name the AI client that pays

Pass `framework` and every request of the payment flow carries
`AIFP-Agent-Framework: <value>`, so the merchant dashboard shows which AI
client paid:

```python
agent = AiFinPayAgent.from_seed(seed_hex, framework="claude")
```

Accepted values: `chatgpt`, `claude`, `perplexity`, `gemini`, `cursor`,
`openai-agents`, `windsurf`, `custom`. Leave it unset and no header is sent.

## Request authentication without payment

The legacy `Agent` class and `agent.pay(url)` sign requests to endpoints that
authenticate agents by key; they do not buy access. Paying is `fetch_paid`.

```python
import os
from aifinpay import Agent

agent = Agent.from_keypair_file(os.path.expanduser("~/agent-wallet.json"))
agent = Agent.from_secret_b58("3RvZm7Gw...")
```

The provider bridge (`call()` to the AiFinPay bridge host) was retired on
2026-10-12, and the Solana Seat invoice flow is closed. Do not pay either.
