Start with the [AiFinPay skill](/skills). It contains separate instructions
for an agent owner buying access and a merchant charging for a site or API.

```bash
npx skills add AiFinPay/skill
```

## Agent owners

For an assistant with MCP support, connect `@aifinpay/mcp` using the
[MCP setup guide](/pay/mcp). For your own application, install the Node or
Python SDK and follow its versioned package documentation.

```bash
# MCP wallet setup
npx @aifinpay/mcp init

# Node application
npm install @aifinpay/agent

# Python application
pip install aifinpay-agent
```

Choose the runtime you use; installing MCP already includes its SDK dependency.
Keep the persistent wallet local and verify its public address in the client.

<Note>
MCP `@aifinpay/mcp` 2.11.4 pays with `payable_fetch` once the owner enables it
([five steps](/pay/mcp)); Node `@aifinpay/agent` 2.9.0 pays with `fetchPaid` and
Python `aifinpay-agent` 2.7.0 with `fetch_paid`. All settle AIFP-1 (splitter
v1.4) on Polygon by default, or on Base when the owner selects it, in the native
currency or USDC; the smallest batch is $0.10 plus gas. A quote or invoice alone
does not move funds. See [payment support](/pay/paywalled-sites).
</Note>

After creating the wallet, link the agent to your account at
[dash.aifinpay.io](https://dash.aifinpay.io) → **My Agents** to see its
balance, payments and receipts. With MCP, **Claim via MCP** gives a one-time
URL for the agent's `agent_claim_self` tool; otherwise use **Add
agent by address** and have the agent sign the challenge
(`signDashboardClaim` in Node, `sign_dashboard_claim` in Python). Set the
agent's working limits there under **Controls**; AiFinPay enforces them on every
quote and receipt.

Ask the agent to inspect the target origin's `/.well-known/x402.json` and its
API catalog. Agree on the resource, receipt scope, batch cost and separate gas
budget before a supported payment is executed. Read [discovery](/ai-discovery)
for the difference between general instructions and site-specific routes.

## Merchants

Open [the dashboard](https://dash.aifinpay.io), register your site and follow
[the merchant onboarding guide](/charge/onboarding). Use the
`aifinpay-merchant` skill to guide integration of `@aifinpay/gate`.

Publish discovery on the same origin as your protected routes. After a real
payment, verify the merchant, amount and transaction in the dashboard; a
quote or HTTP 402 response is not a completed payment.
